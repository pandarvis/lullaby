# Studio V1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans. Exécution autonome autorisée ; pas de nouvelle attente de validation.

**Goal:** Rendre les conversations et outils locaux utilisables quotidiennement.
**Architecture:** Garder le renderer assistant-ui, exposer les actions par un preload typé et validé. Isoler les aperçus du renderer privilégié.
**Tech Stack:** Electron, TypeScript, React, assistant-ui, moteurs officiels existants.
**Spec:** ../specs/2026-09-27-studio-v1-design.md

## Global Constraints

- Windows natif ; aucune dépendance supplémentaire, ni API facturée.
- Iris et SVG ; aucune suppression de dossier projet ; aucun push ou merge partagé.
- Conserver brouillons, contexte natif, skills et règles de permissions.

## Review Focus

- Projet actif retiré pendant une initialisation : refus par verrou du manager.
- Changement de session pendant un dialogue de pièce jointe : aucun mélange.
- HTML hors projet via lien/jonction : confinement par realpath et limite de taille.
- Choix natif après un mode explicite : pas de permission résiduelle non annoncée.
- Moteur absent et compte absent : diagnostics distincts et aucun fallback API.
